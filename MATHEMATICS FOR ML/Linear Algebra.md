# Best Mindset
Don’t memorize formulas blindly.

Always ask:

> “How is this used in ML?”

That makes linear algebra much easier and more interesting.

>Each topic, search on YouTube like: “Scalars for ML”, and after learning that concept, always answer this question: “How is this used in ML?” using Claude or ChatGPT. Also, solve some practice questions.
